### 👋 Olá, eu sou o Pedro Sousa — Full Stack Developer 🚀 ###

Desenvolvedor Full Stack com experiência no desenvolvimento de aplicações web, atuando tanto no Front-End quanto no Back-End. Trabalho principalmente com Next.js, React, TypeScript, JavaScript, Node.js e Express, desenvolvendo interfaces modernas, APIs REST, integrações com bancos de dados e soluções voltadas às necessidades do negócio.

Possuo experiência com bancos de dados MySQL, PostgreSQL, Oracle e SQL Server, além de ferramentas como Postman, DBeaver e Git. Também tenho experiência profissional com GeneXus, atuando no desenvolvimento de sistemas, regras de negócio, modelagem de dados e integração com bancos SQL.

Atualmente, atuo como Desenvolvedor Full Stack na Volkswagen Francauto e curso Análise e Desenvolvimento de Sistemas pela FATEC Franca. Também desenvolvo projetos pessoais e freelances, buscando constantemente evoluir minhas habilidades em desenvolvimento web e engenharia de software.
